# 星际防卫 - 太空射击游戏

一款使用 Pygame 开发的经典纵版射击游戏，玩家控制飞船抵御外星入侵者。

## 游戏玩法
- 使用 **←** 和 **→** 键左右移动飞船
- 按下 **空格键** 发射子弹
- 击落红色外星敌人获得分数
- 敌人会不断下降并随机开火
- 每击败5个敌人游戏等级提升，敌人移动速度加快
- 玩家拥有3条生命，被击中或与敌人相撞会损失生命并短暂无敌
- 敌人到达屏幕底部则游戏结束
- 游戏结束后按 **R** 重新开始，按 **Q** 退出
