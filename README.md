# 🐍 贪吃蛇·终极版

一款使用 Pygame 开发的经典贪吃蛇游戏，拥有**动态难度**、**障碍物**、**特殊食物**、**最高分记录**以及**作弊模式**，界面采用精心搭配的蓝绿渐变色调。

## ✨ 特色功能

- **经典玩法**：用方向键控制蛇移动，吃食物增加长度和分数。
- **动态难度**：蛇的长度越长，移动速度越快（上限 25 帧/秒）。
- **障碍物系统**：每获得 5 分，随机生成一个灰色障碍物，撞上即游戏结束。
- **特殊食物（金色）**：随机出现，吃掉后获得双倍分数并暂时加速 5 秒。
- **最高分记录**：自动保存最高分到 `highscore.txt`。
- **作弊模式（无敌）**：
  - 开启后蛇不会死亡（撞墙从对面穿出，无视自身/障碍物碰撞）。
  - 食物固定出现在蛇头正前方 2 格位置，每次吃掉后立即在前方 2 格刷新新食物。
  - 通过**鼠标右键**随时切换开启/关闭。
- **便捷操作**：
  - 鼠标左键点击：重置游戏（任何时候）
  - 鼠标右键点击：切换作弊模式
  - 回车键：暂停/继续
  - ESC 键：退出游戏

## 🎮 操作说明

| 按键 | 功能 |
|------|------|
| ↑ ↓ ← → | 控制蛇移动方向 |
| 鼠标左键 | 重置游戏 |
| 鼠标右键 | 开启/关闭作弊模式 |
| 回车键 (Enter) | 暂停/继续 |
| ESC 键 | 退出游戏 |
